# แผนที่น้ำท่วมเมืองขอนแก่น · แบบจำลองควบคู่ 1D–2D (Longdo Map)

เว็บแผนที่ Longdo Map 3D แสดงผลแบบจำลอง Drainage 1D2D FV2 ของเมืองขอนแก่น ตัดตามขอบเขต 5 ตำบล
(เมืองเก่า ในเมือง บ้านเป็ด ศิลา พระลับ · 235.8 ตร.กม.) ทุกหน้ามีปุ่มสลับ 2 ชั้นข้อมูล

- **น้ำผิวดิน (surf)**: polygon 3D ความลึกน้ำ สูงตามความลึกจริง × ตัวคูณ "ความสูงน้ำ"
- **น้ำในท่อ (pipe)**: เส้นท่อ 54 สาย (3,024 ช่วงเซลล์) สีตามระดับน้ำเหนือท้องท่อ จุดแดง = จุดระบายออก 8 จุด

## หน้าเว็บ
```
index.html      น้ำท่วมสูงสุด 10 กรณี: เหตุการณ์ 22 ก.ย. 2568 + ฝนออกแบบ 100/500/1,000 ปี × 3 ช่วงปี (SSP2-4.5)
anim.html       แอนิเมชันเหตุการณ์ 22 ก.ย. 2568 (12:00 น. 22 ก.ย. – 12:00 น. 25 ก.ย.) 41 เฟรม
common.js/.css  ส่วนกลาง: Longdo key, สี, ชั้นข้อมูล, ปุ่มควบคุม
scenarios.js    สถิติทุกกรณี + ระดับน้ำในท่อของทุกกรณี (สร้างจากสคริปต์)
anim_event.js   รายการเฟรม + สถิติ + ระดับน้ำในท่อทุกเฟรม (สร้างจากสคริปต์)
pipe_geom.js    รูปทรงเส้นท่อและจุดระบายออก (จาก data/pipe_dir_20m.asc)
tambon.js       ขอบเขตและชื่อ 5 ตำบล (จาก data/KhonKean_Tambon_Run_BD.shp, UTM 47N → WGS84)
vec/surf_<id>.js            polygon น้ำผิวดินสูงสุดของแต่ละกรณี
vec/anim_event/s_NNNNN.js   polygon น้ำผิวดินของแต่ละเฟรม
```
`<id>` = `event`, `100H`, `100N`, `100F`, `500H`, `500N`, `500F`, `1000H`, `1000N`, `1000F`
(H = 1981–2014, N = 2041–2060, F = 2071–2090)

## สร้างข้อมูลใหม่
```
pip install numpy scipy contourpy opencv-python matplotlib
python tools/make_scenarios.py <results_max> <results_base_22sep2025>
python tools/make_frames.py <results_base_22sep2025> --start "2025-09-22 12:00" --dt 900 --pick 0:32:2,36:48:4,60:288:12
```
- `make_scenarios.py` หา `surf<RP><P>_maxd.asc` / `pipe<RP><P>_maxd.asc` ในโฟลเดอร์แรก (รวมโฟลเดอร์ย่อย)
  และ `surf0_maxd.asc` / `pipe0_maxd.asc` ในโฟลเดอร์ที่สอง
- `make_frames.py` ใช้ `surf0_d_NNNNN.asc` และ `pipe0_d_NNNNN.asc` (ทุก 900 วินาที)
  `--pick` = ช่วง "เริ่ม:จบ:ทุก" ของลำดับไฟล์ ค่าเริ่ม = ทุก 30 นาทีถึง 20:00 น., ทุกชั่วโมงถึง 24:00 น., แล้วทุก 3 ชม.
- เกณฑ์น้ำท่วม 0.10 ม. ตามรายงาน · ช่วงสีผิวดิน 0.10/0.25/0.50/1/2/3 ม. · ช่วงสีท่อ 0/0.5/1/2/3/5 ม.
- ความเรียบของ polygon ปรับที่ `tools/kkvec.py` (`UP`, `SIGMA`, `CHAIKIN`, `tol`)

ขนาดไฟล์: แผนที่สูงสุด 2.5–3.0 MB ต่อกรณี · เฟรมแอนิเมชัน ≤ 2.1 MB ต่อเฟรม (รวม ~74 MB) ·
ระดับน้ำในท่อเก็บเป็นตัวเลขต่อช่วงท่อ จึงเล็กมาก

## เปิดใช้งาน
GitHub Pages: Settings → Pages → branch `main`, folder `/ (root)` หรือเปิด `index.html` จากเครื่องได้เลย
(ข้อมูลโหลดด้วย `<script>`)

## Longdo API key
อยู่ใน `common.js` (`const API_KEY`) ใช้ key เดียวกับโครงการหาดใหญ่ ทุกคนที่เปิดหน้าเว็บเห็น key ได้
ควรจำกัดโดเมนของ key ที่ map.longdo.com/console · เปลี่ยนชั่วคราวได้ด้วย `?key=...` ต่อท้าย URL

## ข้อควรทราบในการอ่านผล
แบบจำลองไม่คิดการซึม น้ำในแอ่งปิดจึงค้างจนจบการจำลอง · พื้นที่ท่วมรวมบึงและลำน้ำที่มีน้ำขัง ·
ระดับน้ำในท่อเกินความสูงท่อ (1.2–3.0 ม. สำหรับท่อลอดเหลี่ยม) = ท่อเต็มและมีแรงดัน
